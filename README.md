# 📈 نظام إدارة محفظة البورصة المصرية

نظام احترافي لإدارة محفظتك في البورصة المصرية — بُني بلغة Python مع Flask وواجهة ويب عربية كاملة.

---

## 🗂️ هيكل المشروع

```
portfolio/
├── app.py                          ← نقطة التشغيل الرئيسية
├── requirements.txt                ← المكتبات المطلوبة
├── database/
│   ├── __init__.py
│   └── db.py                       ← قاعدة البيانات SQLite
├── services/
│   ├── __init__.py
│   ├── portfolio_service.py        ← منطق العمل (شراء / بيع / إيداع / سحب)
│   └── price_fetcher.py            ← جلب أسعار الأسهم من الإنترنت
├── routes/
│   ├── __init__.py
│   └── api.py                      ← API endpoints
├── templates/
│   └── index.html                  ← واجهة المستخدم
└── static/
    ├── css/style.css               ← التصميم
    └── js/app.js                   ← منطق الواجهة
```

---

## ⚡ طريقة التشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق
```bash
python app.py
```

### 3. افتح المتصفح
```
http://localhost:5000
```

---

## 🛠️ العمليات المتاحة

| العملية | الوصف |
|---------|-------|
| **إيداع** | إضافة رصيد نقدي للحساب |
| **سحب** | سحب رصيد من الحساب (مع التحقق من الرصيد الكافي) |
| **شراء** | شراء أسهم مع حساب المتوسط التلقائي |
| **بيع** | بيع أسهم مع حساب الربح/الخسارة |

---

## 🔒 التحقق من الأخطاء

- ❌ منع السحب أكثر من الرصيد المتاح
- ❌ منع بيع أسهم أكثر من المملوكة
- ❌ منع شراء أسهم غير موجودة في البورصة المصرية
- ❌ منع الشراء بدون رصيد كافٍ

---

## 📊 المميزات

- حساب **المتوسط المرجح** تلقائياً عند الشراء المتكرر
- جلب **السعر الحالي** من الإنترنت تلقائياً
- **سجل كامل** لجميع العمليات مع فلتر بالنوع
- حساب **الربح/الخسارة** بالجنيه والنسبة المئوية
- **50+ سهم** مصري مدرج مسبقاً
- إمكانية إضافة أسهم مخصصة

---

## 🔄 تحديث أسعار الأسهم

الأسعار تُجلب تلقائياً من مصادر متعددة:
1. Mubasher (مباشر)
2. Investing.com

> **ملاحظة:** بعض الأسعار قد تظهر كـ `--` إذا لم يكن الموقع متاحاً. يمكن تحديث الأسعار يدوياً بالضغط على زر "تحديث الأسعار".

---

## 🏗️ التوسعة والتعديل

كل وظيفة منفصلة في ملفها الخاص:
- لإضافة مصدر سعر جديد → عدّل `services/price_fetcher.py`
- لإضافة عملية جديدة → عدّل `services/portfolio_service.py` و `routes/api.py`
- لتعديل الواجهة → عدّل `templates/index.html` و `static/`
